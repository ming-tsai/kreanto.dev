# Security policy

## What this project is

kreanto.dev is a static website. It has no server code, no database, no user accounts and no secrets in the repository. The realistic risks are a vulnerable dependency, a malicious script added to the page, or a mistake in the hosting settings.

## Reporting a problem

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**. If that option is not available, open a public issue that says only "I have a security report" and no details, and I will contact you.

Include what you found, how to reproduce it, and what you think the impact is.

## What to expect

This is a personal project maintained in spare time. I aim to reply within 7 days. There is no bounty program.

## Supported versions

Only the current `main` branch and the live site are supported.
